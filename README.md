# SEngine

**SEngine** — это минималистичная поисковая система, предназначенная для быстрого нахождения веб-ресурсов по их доменному имени и заголовку страницы. Проект построен на базе serverless-архитектуры и работает в режиме реального времени.

## ✨ Особенности

* **Двухэтапная фильтрация:** Поиск совпадений по URL-адресу с последующим отсевом результатов по содержимому тега `<title>`.
* **DNS-верификация:** Автоматическая проверка активности домена и отображение его текущего IP-адреса.
* **Высокая скорость:** Асинхронный параллельный конвейер обработки данных.
* **Serverless:** Полное отсутствие традиционных серверов благодаря развертыванию в облаке.

## 📁 Структура проекта

* `/` — Фронтенд-интерфейс поисковика (разворачивается на GitHub Pages).
* `src/index.js` — Бэкенд-логика поискового движка.
* `wrangler.json` — Конфигурационный файл для деплоя бэкенда в Cloudflare.
* `package.json` — Манифест зависимостей среды выполнения Node.js.

## 🚀 Быстрый запуск

### 1. Настройка бэкенда (Cloudflare Workers)
1. Установите Wrangler CLI и авторизуйтесь в своей панели управления Cloudflare.
2. Опубликуйте бэкенд-приложение с помощью команды:
   ```bash
   npm run deploy
   ```
3. Скопируйте полученный URL-адрес вашего развернутого воркера (например, `https://workers.dev`).

### 2. Настройка фронтенда (GitHub Pages)
1. Откройте файл `index.html`.
2. Найдите строку конфигурации `const WORKER_URL = '...'` и вставьте скопированный адрес вашего воркера.
3. Загрузите файл в ваш репозиторий GitHub и включите **GitHub Pages** в настройках проекта.
